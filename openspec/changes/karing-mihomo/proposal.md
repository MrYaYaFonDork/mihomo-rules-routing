# Karing → Mihomo: наборы правил

## Why

Получать выбранные наборы Karing в форматах Mihomo (MRS/classical YAML) с
готовыми ссылками для rule-providers. Пользователь подтвердил личное
некоммерческое использование 2026-11-15.

## What Changes

- Конвертация 46 выбранных SRS из единого snapshot KaringX/karing-ruleset.
- MRS для совместимых domain/ipcidr; classical YAML для остальных поддержанных правил.
- Проверяемая сборка, манифест, Actions, README и лицензионные оговорки.
- Профили и шаблоны клиентов (включая Remnawave) в репозиторий не входят.

## Impact

Новый проект в текущей директории. Личные профили, домены и SSH-ключи не
публикуются. Коммит, push и публикация не разрешены текущим заданием.
