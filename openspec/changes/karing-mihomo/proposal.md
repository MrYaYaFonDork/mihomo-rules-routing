# Karing → Mihomo для личного использования

## Why

Дополнить существующий пользовательский MIHOMO Subscription Template Remnawave
наборами и политикой Karing, сохранив действующие настройки. Пользователь подтвердил
личное некоммерческое использование 2026-11-15.

## What Changes

- Конвертация 46 выбранных SRS из единого snapshot KaringX/karing-ruleset.
- MRS для совместимых domain/ipcidr; classical YAML для остальных поддержанных правил.
- Отдельный локальный пользовательский шаблон; исходный не изменяется.
- Проверяемая сборка, манифест, Actions, README и лицензионные оговорки.

## Impact

Новый проект в текущей директории. Личный профиль, домены и SSH-ключи не публикуются.
FlClashX Windows/Android/Linux, Clash Mi iOS; проверки на устройствах обязательны
перед заявлением о совместимости. Коммит, push, публикация, изменение панели и её
Response Rules не разрешены текущим заданием.
