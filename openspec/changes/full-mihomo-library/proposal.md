# Полная библиотека правил Karing для Mihomo

## Why

Текущие 46 выбранных SRS не представляют полную библиотеку Karing.

## What Changes

- Инвентаризация всех SRS одного зафиксированного commit ветки sing.
- Формирование отдельных providers Mihomo без изменения семантики, с явным учётом неподдержанных источников и происхождения.
- Проверка полной сборки и безопасная публикация одного снимка в ветку rules.
- Клиентские профили, личные маршруты и файлы .dat не входят в состав.

## Impact

Затронуты сборщик, конфигурация, проверки, CI и документация. Лицензионный gate остаётся закрытым до отдельного решения.
